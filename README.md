**wayofpy** is a opensource Python infrastructure org focused on building high-performance, free-threaded Python systems that eliminate traditional concurrency limitations. We're reimagining Python for modern distributed systems and high-performance applications.

## Our Mission

To build the next generation Python infrastructure that delivers:

- Free-threaded Python execution without GIL limitations
- True parallelism through threaded architectures
- High-performance ASGI/WSGI frameworks
- Scalable agent-based systems
- Low-latency, production-ready Python components

## Core Projects

### karak - Free-Threaded Python Framework

The **karak** project provides a threaded HTTP framework for Python that delivers true parallelism without async complexity. It's designed for high-performance applications where traditional async approaches fall short.

- **Key Features**: Thread-based concurrency, no GIL restrictions, high-throughput HTTP handling
- **Performance**: 2-5x faster than traditional async frameworks
- **Website**: [karak.wayofpy.com](https://karak.wayofpy.com)

### osso - Agent Primitives for Free-Threaded Python

**osso** provides the fundamental building blocks for concurrent agents in Python. These primitives enable the creation of sophisticated, stateful agents that can operate efficiently in threaded environments.

- **Key Features**: Agent state management, message passing, lifecycle controls
- **Use Cases**: Distributed agents, microservices, concurrent task execution
- **Website**: [osso.wayofpy.com](https://osso.wayofpy.com)

### zinda - Python Infrastructure Components

**zinda** is a collection of low-level infrastructure components that power the wayofpy ecosystem. It includes optimized networking layers, serialization primitives, and utility functions designed for high-performance Python applications.

- **Key Features**: High-performance networking, efficient data serialization, utility functions
- **Website**: [zinda.wayofpy.com](https://zinda.wayofpy.com)
